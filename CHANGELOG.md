# Changelog

## 0.2.0 — 2026-09-18

- Restructured the repository root as the standard installable WordPress plugin root.
- Added bundled runtime autoloading with no Composer installation requirement.
- Added the standalone workstation, deterministic history, watchlists, portfolios, positions, risk analytics, and transactional paper trading.
- Added WordPress `readme.txt`, developer README, distribution rules, translation directory, and corrected documentation paths.
- Added safe capability cleanup during uninstall while retaining financial data by default.

## 0.1.0 — 2026-09-18

- Established the initial namespaced plugin foundation, provider contracts, security-master primitives, REST quote API, migrations, audit events, and financial golden tests.
